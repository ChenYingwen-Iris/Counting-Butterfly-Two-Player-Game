# Counting-Butterfly-Two-Player-Game
**Counting Butterfly!** - Fast-paced pixel game for 2 players. Count butterflies that flash on screen in groups of 1-4. Three levels with increasing counts. Race to input correct numbers using W/S (Red) or Arrow keys (Blue). First correct: 10 points, second: 5 points. Quick reflexes win! Red/blue color theme. Perfect for competitive fun.
